# Originium_WLF — сайт-карточка разработчика

Одностраничный сайт-визитка с проектами. Чистая статика: HTML + CSS + JavaScript,
без сборки, фреймворков и зависимостей.

## Возможности

- **Тёмная и светлая темы** — тёмная по умолчанию, выбор сохраняется в `localStorage`,
  переключение кнопкой в шапке или клавишей `T`.
- **Кастомный курсор** — точка с инерцией и кольцо, меняющее форму над ссылками,
  кнопками, карточками и текстом. На тач-устройствах автоматически отключается.
- **Анимации** — прелоадер, посимвольный выезд заголовка, глитч, печатная машинка,
  появление блоков при скролле, счётчики, 3D-наклон карточек, бегущая строка.
- **Живой фон** — canvas с частицами и связями, реагирующими на курсор, плюс
  плавающие градиентные пятна и сетка.
- **Адаптивность** — от 320px до широких экранов, мобильное меню.
- **Доступность** — семантическая разметка, видимый фокус, полное уважение к
  `prefers-reduced-motion` (тяжёлые анимации выключаются).

## Структура

```
index.html        разметка
css/style.css     стили, токены тем и анимации
js/data.js        КОНТЕНТ: проекты, стек, контакты, роли
js/main.js        логика: тема, курсор, частицы, рендер, скролл
```

## Как обновить содержимое

Весь контент лежит в `js/data.js` — трогать остальные файлы не нужно.

### Добавить проект

```js
const PROJECTS = [
  {
    title: 'Название',
    tagline: 'Короткое описание одной строкой',
    description: 'Развёрнутое описание проекта.',
    tags: ['Web', 'TypeScript'],   // первый тег становится категорией в фильтрах
    status: 'live',                // live | wip | archived
    year: '2026',
    links: [{ label: 'GitHub', url: 'https://github.com/...' }],
  },
  // ...
];
```

### Другое

- `ROLES` — строки для эффекта печатной машинки в шапке.
- `STACK` — группы технологий (они же попадают в бегущую строку).
- `CONTACTS` — ссылки; `icon` принимает `github`, `telegram`, `discord`, `mail`.

Цифры в блоке статистики задаются прямо в `index.html` атрибутом `data-to`.

## Настройка внешнего вида

Цвета, радиусы и тайминги — CSS-переменные в начале `css/style.css`:
`:root` отвечает за тёмную тему, `[data-theme='light']` — за светлую.
Достаточно поменять `--accent` и `--accent-2` (и парные `--accent-rgb`,
`--accent-2-rgb`), чтобы перекрасить весь сайт.

## Запуск

Отдельная сборка не нужна — достаточно открыть `index.html`.
Для локального сервера:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

Деплой — любой статический хостинг (GitHub Pages, Netlify, Vercel).
